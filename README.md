# Askeby 3D – programuppdateringar

Det här förrådet innehåller färdigbyggda programuppdateringar för Askeby 3D,
en interaktiv museimonter av Tellway Pictures AB.

- Varje version under **Releases** innehåller programpaket (`.paket`), ett
  manifest och signaturer.
- Paketen är signerade med Tellway Pictures nyckel. En monter installerar
  bara uppdateringar med giltig signatur.
- Här finns ingen källkod och inget innehåll – inga texter, modeller eller
  bilder från något museum.
