# Tellway Pictures – programuppdateringar

Det här förrådet innehåller färdigbyggda programuppdateringar för Tellway
Pictures AB:s program, till exempel Tellway 3D.

- Varje program har en egen mapp, t.ex. `tellway-3d/`. Filen `senaste.json`
  där pekar ut den senaste versionen och är signerad med Tellway Pictures
  nyckel.
- Programpaketen (`.paket`) ligger under **Releases**.
- Programmen installerar bara uppdateringar med giltig signatur, och bara
  sådana som gäller just dem.
- Här finns ingen källkod och inget innehåll – inga texter, modeller eller
  bilder från någon kund.
